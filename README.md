# Tropas dos Lanternas

Guia de fãs sobre as nove Tropas dos Lanternas da DC. Explore o espectro, conheça os anéis de poder e descubra as entidades, os personagens e as histórias ligados a cada tropa.

## Como abrir o site

Baixe ou clone o repositório e abra o arquivo [`app/index.html`](app/index.html) no navegador. O site usa HTML, CSS e JavaScript e roda direto da pasta do projeto.

Na página inicial, selecione uma tropa para ver sua origem, seus integrantes, os poderes do anel, a entidade associada e uma história para conhecer.

## Estrutura do projeto

- [`app/`](app/) reúne as páginas, o código e as ilustrações do site.
- [`docs/`](docs/) reúne o [guia de conteúdo](docs/Tropas_dos_Lanternas_DC.md) e o [UI kit](docs/Lanteras_UI_KIT.md).
